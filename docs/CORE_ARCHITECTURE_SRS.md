# معمارية النظام الأساسية (Core Architecture SRS)

يحدد هذا المستند البنية التحتية المحاسبية والإدارية للنظام، والتي ترتكز على الفصل التام للبيانات مع دعم التوسع الداخلي للشركات.

## 1. قواعد البيانات المنفصلة (Multi-Tenant Architecture)
- **العزل التام (Data Isolation):** كل شركة (Tenant) تشترك في النظام تحصل على **قاعدة بيانات منفصلة تماماً** خاصة بها. هذا يضمن أعلى معايير الأمان، السرعة في الاستعلامات، وسهولة أخذ النسخ الاحتياطية (Backups) لكل شركة على حدة.
- يتم تحديد قاعدة البيانات تلقائياً بناءً على النطاق الفرعي (Subdomain) الذي يدخل منه المستخدم عبر حزمة `spatie/laravel-multitenancy`.

## 2. الفروع (Multi-Branch Support)
قاعدة البيانات الواحدة (الشركة الواحدة) يمكن أن تتوسع داخلياً لتدعم عدة فروع مترابطة محاسبياً ولكن منفصلة إدارياً.

### أ. هيكل الفروع:
- جدول مخصص للفروع `branches` (رقم الفرع، اسم الفرع، العنوان).
- **ربط الكيانات (Entity Relations):**
  - كل مستخدم (User) يُربط بفرع معين (أو المركز الرئيسي).
  - كل مخزن (Warehouse) يُربط بفرع.
  - كل صندوق/خزينة (Safe/Fund) يُربط بفرع.
  - كل فاتورة (Invoice) وسند (Voucher) يسجل عليه `branch_id` لتحديد الفرع الذي تمت فيه الحركة.

### ب. الصلاحيات والتقارير:
- المستخدم العادي يرى ويتعامل فقط مع حركات المخازن والصناديق التابعة للفرع الخاص به.
- التقارير المحاسبية (ميزان المراجعة، الأرباح والخسائر) يمكن فلترتها لعرض نتائج فرع محدد (تعمل كمراكز تكلفة Cost Centers) أو عرض الموقف المالي المجمع للشركة ككل.

## 3. المدد/الفترات المالية (Fiscal/Financial Periods)
لا يعمل النظام بنظام السنة المفتوحة دائماً لحماية البيانات المحاسبية، بل يعتمد على "المدد المالية".

### أ. هيكل المدد المالية:
- جدول المدد المالية `financial_periods` يحتوي على (تاريخ البداية، تاريخ النهاية، اسم السنة/المدة، والحالة: مفتوحة / مغلقة).
- لا يمكن إضافة، تعديل، أو حذف أي حركة (فاتورة أو قيد يومية) في تاريخ يقع ضمن **مدة مالية مغلقة**.

### ب. إقفال السنة (Year-End Closing):
- عند انتهاء المدة المالية، يقوم النظام بعملية "إقفال السنة":
  1. ترصيد حسابات قائمة الدخل (الإيرادات والمصروفات) وإقفالها في حساب "الأرباح المبقاة" (Retained Earnings).
  2. تدوير الأرصدة الختامية لحسابات الميزانية (الأصول، الخصوم، حقوق الملكية) لتصبح "أرصدة افتتاحية" للمدة المالية الجديدة.
  3. تغيير حالة المدة المالية القديمة إلى "مغلقة" (Closed).
